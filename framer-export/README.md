# Obsah pro Framer

Vygenerováno `build-framer-export.py` z `content/`. Needituj ručně —
zdroj je v `content/`, tohle je jen výstup pro copy-paste do Frameru.

| Soubor | Co v něm je |
|---|---|
| `domovska.md` | Domovská stránka — hero, statistiky, kontakty |
| `sluzba-*.md` | 6 podstránek služeb včetně FAQ |
| `clanek-*.md` | 5 článků na blog |
| `clanek-{en,ru,ua}-*.md` | Tytéž články v mutacích |
| `pravni-*.md` | Zásady ochrany osobních údajů, obchodní podmínky |
| `pravni-{en,ru,ua}-*.md` | Právní texty v mutacích |
| `cenik.csv` | 43 ceníkových položek (oddělovač `;`, UTF-8 BOM) |
| `cenik-{en,ru,ua}.csv` | Ceník v jazykových mutacích |
| `preklady-*.md` | Kompletní překlady do EN, RU a UA |

Obrázky a video zůstávají v `assets/` — do Frameru se nahrávají přímo.

Výběr šablony a srovnání cen je ve [FRAMER.md](../FRAMER.md).
